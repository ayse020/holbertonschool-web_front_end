# Holberton School - CSS Advanced Project

## 🎯 Layihə Məqsədi

Bu layihə CSS-in qabaqcıl xüsusiyyətlərini öyrənmək üçün nəzərdə tutulub. 32 addımda CSS-də aşağıdakı konsepsiyalar öyrənilir:

- CSS Custom Properties (Dəyişənlər)
- CSS Grid və Flexbox
- Responsiv Dizayn
- Animasiya və Keçidlər
- Modern Layout Texnikaları
